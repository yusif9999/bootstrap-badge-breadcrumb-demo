# Support Ticket Management Dashboard

## Overview
A fully responsive, single-page front-end user interface designed for a customer support and ticket management system. This project was built exclusively using **HTML5** and **Bootstrap 5**, focusing on the practical implementation of core Bootstrap layout utilities and UI components without relying on external custom CSS.

## Key Bootstrap Features Showcased
*   **Breadcrumbs:** Implemented for clear user navigation and hierarchical page tracking.
*   **Badges:** Utilized within the data tables to visually indicate different ticket statuses (e.g., Urgent, In Progress, Resolved).
*   **Grid System & Flexbox:** Used to create a fluid layout that adapts seamlessly across mobile, tablet, and desktop screens (utilizing `d-none`, `d-md-block`, etc.).
*   **Alerts:** Integrated for system-wide announcements and notifications.
*   **Responsive Tables:** Clean data presentation with hover states and mobile-friendly scrolling.

## Technologies Used
*   HTML5
*   Bootstrap 5.3.8
*   Bootstrap Icons
*   FontAwesome
